# TodoMarket · Angular

Cliente web del supermercado. Ejecuta `npm ci` y `npm start`, y abre [localhost:4200](http://localhost:4200). Usa el Backend en el puerto 8184 para productos y usuarios.

Para generar la aplicación estática, ejecuta `npm run build`. Configura `TODOMARKET_API_BASE_URL` antes de ejecutar cualquiera de los dos comandos si el Backend usa otra URL. Consulta el [README del proyecto](../README.md) para iniciar los microservicios y MongoDB.
